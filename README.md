# Ludovica Sidoti - Personal Website

This is the source code for Ludovica Sidoti's personal website, hosted on GitHub Pages.

## Viewing the Site

Once deployed, the site will be available at: https://davidorban.github.io/ludovicasidoti/

## Local Development

To view the site locally, simply open `index.html` in your web browser.

## Deployment

The site is automatically deployed through GitHub Pages. Any changes pushed to the main branch will be reflected on the live site.

## Customization

Edit `index.html` to customize:
- Personal information
- Contact details
- Sections and content
- Styling and colors
